# Architecture

The React/MapLibre client is public and read-only. Nginx serves the static client and same-origin proxies published project, feature, map and geocoder requests to a private Fastify API. The explicit public DTO is the visitor boundary; source manifests, review inputs and workflow files remain internal. Static curated packages are the default runtime repository; an operator-managed PostGIS store may be configured through `DATABASE_URL`. Git-versioned source manifests and import files are validated by CLI before deployment. Country adapters normalise source-specific records into the neutral domain model. Tile and geocoder services are private operator dependencies.
